# 📊 لوحة تتبع العادات (Habits Dashboard)

لوحة تحكم تفاعلية باللغة العربية لمتابعة العادات اليومية، تعرض الإحصائيات بشكل مرئي ومبسط.

## ✨ المميزات
- **تتبع يومي:** تعليم العادات المنجزة بضغطة زر.
- **حفظ تلقائي:** يتم حفظ تقدمك في المتصفح (LocalStorage) فلا يضيع عند إغلاق الصفحة.
- **إحصائيات فورية:** حساب نسبة الالتزام الأسبوعية وأطول سلسلة إنجاز (Streak).
- **رسوم بيانية تفاعلية:** رسم عمودي لآخر ٧ أيام، ورسم دائري لتوزيع العادات حسب التصنيف (باستخدام Chart.js).
- **وضع ليلي:** يدعم الوضع النهاري والليلي مع حفظ التفضيل.
- **تصميم متجاوب:** يعمل بشكل ممتاز على الجوال والكمبيوتر.

## 🛠️ التقنيات المستخدمة
- **HTML5** (هيكل الصفحة)
- **CSS3** (التنسيق، المتغيرات، والوضع الليلي)
- **JavaScript** (المنطق، التفاعل، وإدارة الحالة)
- **Chart.js** (الرسوم البيانية)
- **GitHub Pages** (الاستضافة)

## 🚀 طريقة التشغيل محلياً
1. قم بتحميل المشروع (Download ZIP أو عبر `git clone`).
2. افتح ملف `index.html` في أي متصفح.
3. ابدأ بإضافة عاداتك وتعليمها!
